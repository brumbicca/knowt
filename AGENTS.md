- **knowt** = fábrica de compreensão de sistemas (chat + Insights).
- **Fiesta** (`c:\Apps\fiestaup`) = outro produto. **Não** alterar o Fiesta “para virar knowt”.

## Regras

1. Zero verdade silenciosa — capabilities `live` só com evidência + gate.
2. Hermes / catálogo: DoD em `.cursor/rules/hermes-contract-dod.mdc` (quando o bridge existir).
3. Piloto: Tiny; single-tenant no MVP.
4. Não prometer “responde tudo o ERP” sem cobertura comprovada.
5. Credenciais: nunca no chat; secret refs / cofre.
6. Antes de deploy em VPS knowt: actualizar `HANDOFF.md`.
